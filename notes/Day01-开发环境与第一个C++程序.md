## 一、今日知识点

### 1. 开发环境
- 编译器：本机使用 MSYS2 自带的 g++（路径 `C:\msys64\ucrt64\bin\g++.exe`），也可以用 Dev-C++ / Visual Studio。
- 编译命令：`g++ -Wall 源文件.cpp -o 程序名.exe`，`-Wall` 表示打开所有常用警告，能帮新手提前发现问题。
- 运行：在终端输入 `.\程序名.exe`。

### 2. C++ 程序的基本结构
```cpp
#include <iostream>      // 引入输入输出库（头文件）
using namespace std;     // 使用 std 命名空间，之后可直接写 cout/cin

int main() {             // main 函数：程序唯一入口，从这里开始执行
    cout << "Hello World!" << endl;
    return 0;            // 返回 0 表示程序正常结束
}
```
- `main` 函数是程序的入口，有且只有一个。
- 每条语句以分号 `;` 结尾。
- `#include <iostream>` 是预处理指令，使用 `cin` / `cout` 必须包含它。

### 3. 基本输入输出
| 写法 | 作用 |
| --- | --- |
| `cout << 内容 << endl;` | 输出内容并换行（`endl` 还会刷新缓冲区） |
| `cin >> 变量;` | 从键盘读入数据，`>>` 会自动跳过空格/回车 |
| `// 注释` 与 `/* 注释 */` | 单行注释、多行注释，编译器会忽略 |

## 三、遇到的报错与解决

1. **报错：`'cout' was not declared in this scope`**
   - 原因：漏写 `using namespace std;`，cout 的全名是 `std::cout`。
   - 解决：补上 using 声明，或者每次写 `std::cout`。

2. **中文在终端里显示乱码**
   - 原因：g++ 默认按 UTF-8 输出，而 Windows 终端默认是 GBK 代码页。
   - 解决：运行前执行 `chcp 65001` 切到 UTF-8 代码页；或编译时加 `-fexec-charset=GBK`。

3. **细节：`12 / 4 = 3` 而不是 3.0**
   - 原因：两个 int 相除，结果仍是 int，小数部分被直接丢弃。
   - 留坑：明天学基本类型时验证 `3 / 2` 与 `3.0 / 2` 的区别。

## 四、一句话总结

C++ 程序从 `main` 函数开始，`#include <iostream>` 提供输入输出能力，`cout` 负责打印、`cin` 负责读入，语句用分号结束。
